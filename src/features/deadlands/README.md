# DEADLANDS: SURVIVAL module

Phase 1 scaffold for a browser-based survival PvE game integrated into the DS1 projects runner.

## Structure

- config: shared constants and phase metadata
- data: reserved for loot tables, recipes and content catalogs
- engine: Phaser bootstrap and runtime initialization
- scenes: Phaser scenes
- state: Zustand store for UI/runtime coordination
- types: shared Deadlands types
- ui: reserved for game HUD and menus
