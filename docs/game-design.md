# Game Design

## Core Loop

EXPLORE -> COLLECT -> CRAFT/BUILD -> HIRE -> AUTOMATE -> EARN GOLD

## Resources

- WOOD
- STONE
- IRON
- GOLD

## Economy

Market conversion batches:

- 100 WOOD = 50 GOLD
- 100 STONE = 75 GOLD
- 100 IRON = 150 GOLD

## Progression

- Levels 1-5 from XP thresholds.
- Quests grant XP + GOLD.
- Achievements unlock by milestones.
- Win condition: 10,000 GOLD, then REALM COMPLETED.

## Validation

All gather/build/hire/sell actions are server validated.
Cooldowns are enforced server-side.
